AVR ADC to PWM Control

Overview

This project demonstrates Analog-to-Digital Converter (ADC) reading and Pulse Width Modulation (PWM) output using the ATmega328P microcontroller.

Tools Used

- MPLAB X IDE
- Proteus Design Suite
- ATmega328P

Working Principle

1. ADC reads an analog input.
2. The ADC value is converted into a PWM duty-cycle value.
3. PWM output changes according to the analog input.

Project Type

Simulation-based embedded systems project.

Status

ADC and PWM firmware developed. Simulation results should be verified before claiming successful testing.
