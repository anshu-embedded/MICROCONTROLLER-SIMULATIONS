# Traffic Light Controller using AVR

## Project Overview

A 4-way traffic light controller implemented using AVR microcontroller and simulated in Proteus.

## Features

- Four-direction traffic control
- Green, Yellow and Red signal sequencing
- Timer-based operation
- Continuous loop execution

## Tools Used

- AVR Microcontroller
- Embedded C
- Proteus

## Future Improvements

- Pedestrian crossing button
- Emergency mode
- Smart traffic control
